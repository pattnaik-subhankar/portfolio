## Note on scoring method

Scores come from evidence on disk, not from commit counts. `project-agents` has been idle 72 days, so git activity alone would have scored this period as a total loss. It was not. The evidence that mattered was in `cerebral-launch` file state, the cron run history, and the dashboard's own drift against its data file.

The Infra layer was marked down on purpose. Capability growth and reliability decay happened in the same six weeks, and an overall score that only counts what got built would have hidden the fact that the measuring instrument was broken the whole time.
